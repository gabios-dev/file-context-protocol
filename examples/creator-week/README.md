# Example: a creator's week (fictional)

Maya is a fictional creator who sells a small online course about home baking. This week she needs reel scripts, captions, a newsletter and an update to her landing page.

She uses several tools side by side:
- **Agada** as the supervisor: it watches the shared folder, checks each piece of work against the brief, and keeps the project record.
- **Claude desktop** for writing drafts, and **ChatGPT desktop** for caption variants, so one task hands off to another tool.
- **Canva** for visuals, which she exports into the folder.
- A **Drive-synced folder** so every tool, on her laptop or phone, sees the same files.

Each tool reads `WORK-TREE.md`, takes the task assigned to it, puts its output in `drafts/`, writes a short report, and marks the task done. Nothing is published until Maya approves it.

This is a made-up scenario showing how FCP can connect tools. It doesn't describe a shipped Agada feature.

Snapshot taken mid-week: C-01 is done, C-02 is in progress, and C-03 and C-04 are waiting.

This example uses the light form of FCP: tasks are described in the table instead of separate task files, and "done" points to a saved file instead of a commit.
