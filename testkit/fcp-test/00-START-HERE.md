This folder is an FCP test queue. `WORK-TREE.md` is the source of truth; follow its loop.

## Rules
- Work only inside this folder. Don't read or change anything outside it.
- No network access. No installs.
- Re-read `WORK-TREE.md` from disk before each task and after each step.
- Read `## Messages from supervisor` every cycle, follow it, and change `Status: open` to `Status: ack` after acting.
- You may change only the State and Note cells of the task table, and the `Status:` lines of messages.
- Put outputs in `drafts/`, reports in `reports/`.
- This folder has no git; a task is done when its output file and report exist. Mark it `[x] done <output file>`.
