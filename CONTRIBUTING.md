# Contributing

Thanks for helping shape FCP.

- **Issues:** report what broke in a real run, which agent you used, and the relevant WORK-TREE snippet (no secrets).
- **Spec changes:** open an issue first. Keep FCP plain files and readable by any agent.
- **Templates and prompts:** PRs welcome, especially prompts tested with a specific desktop agent (say which one and its version).
- Keep examples fictional and free of personal data.
